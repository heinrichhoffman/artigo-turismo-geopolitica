# artigo-turismo-geopolitica

# Impacto Geopolítico no Turismo Brasileiro (Conflito 2026) 🇧🇷

Este repositório contém a pesquisa completa sobre como o conflito Irã-EUA afetou o fluxo turístico para o Brasil, utilizando modelos de **Inferência Causal Bayesiana**.

## 🚀 Destaques da Análise
* **Turismo de Longa Distância (H1):** Aumento causal de **+77%** ($p=0.007$). O Brasil atuou como um *Safe Haven*.
* **Turismo Regional (H2):** Resiliência com alta de **+88%**, demonstrando a estabilidade do mercado sul-americano.

## 📂 Organização do Projeto
Os scripts e dados estão organizados conforme a estrutura de diretórios local:
* `01_dados_brutos/`: Bases da Embratur, GPR Index e dados econômicos.
* `03_resultados/`: Tabelas consolidadas e o arquivo `master_data.csv`.
* `scripts/`: Códigos Python para limpeza e scripts R para modelagem bayesiana.

## 🛠️ Tecnologias Utilizadas
* **Python (Pandas/Yahoo Finance):** Engenharia de dados e integração de variáveis macroeconômicas.
* **R (CausalImpact):** Inferência causal e projeção de contrafactuais sintéticos.
* **GPR Index:** Métrica de risco geopolítico para controle de incerteza global.
